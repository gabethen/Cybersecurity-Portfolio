# Week 6 Review — Home Lab & Windows Security Investigation

## What I Learned

I learned how to create and configure a Windows 11 ARM64 virtual machine and how to use it as a cybersecurity lab environment. I also learned how to locate Windows Security Event IDs and review the information contained within those events.

## Technical Skills Practiced

I practiced locating Event IDs in Windows Event Viewer and understanding what different fields within an event mean. I also practiced identifying important investigation details such as the account name, logon type, source network address, timestamp, and failure reason.

## Investigation Skills

I practiced using a virtual machine to access and investigate Windows Security Event Logs. I learned how to examine an individual event and use the information within the event to better understand what happened.

## Key Lesson

Not every security event is malicious. An event needs to be investigated in context before determining whether the activity is suspicious or legitimate.

## Challenges

One of my challenges was understanding and memorizing different Event IDs and learning what information is important when investigating them. I am still developing my ability to quickly recognize what different event fields mean and how they relate to an investigation.

## What I Want to Improve

I want to continue improving my investigation skills and become more comfortable analyzing Windows Security Event Logs. I also want to improve my ability to recognize important Event IDs and understand how multiple events can be correlated during an investigation.

## Conclusion

Week 6 gave me hands-on experience building a Windows 11 ARM64 virtual machine and investigating Windows Security Event Logs. This was an important step toward building a home SOC environment and developing practical skills that I can continue using in future investigations.
